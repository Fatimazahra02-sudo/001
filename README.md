Dossiers

	•	node_modules/ : contient les bibliothèques installées (React, Vite...).
	•	public/ : contient les fichiers fixes (icône, images).
	•	src/ : contient le code de l'application. C'est là qu'on travaille.
Fichiers indispensables

	•	index.html : la page de base, avec <div id="root"> où React s'affiche.
	•	src/main.jsx : le point d'entrée, il affiche App dans root.
	•	src/App.jsx : le composant principal.
	•	package.json : liste les dépendances et les commandes du projet.
jsx : composants React (JavaScript + HTML)
	•	.css : le style
	•	.json : la configuration
